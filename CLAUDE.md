# Студия Ярослава — сайты на заказ

Репозиторий публичный. Здесь код демо, концептов и портфолио (GitHub Pages: https://cbyatoy.github.io/sites/), шаблоны документов и инструкции агентов.

**В начале работы определи свою роль** из первого сообщения пользователя и прочитай свой файл в `agents/`:
- Координатор — `agents/00-coordinator.md`
- Клиенты — `agents/01-clients.md` + `agents/shared/client-intake-checklist.md`
- Поиск — `agents/02-leads.md`
- Сайты — `agents/03-sites.md`

Всегда соблюдай `agents/shared/rules.md`. Если роль не указана — спроси.

Главное правило: **никаких данных клиентов в репозитории** (телефоны, переписка, реквизиты, статусы). Они живут в закрытом документе Claude Docs «Студия — CRM».
