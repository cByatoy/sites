# Общие правила студии (читают все агенты)

## Кто мы
- **Ярослав** — самозанятый (НПД), делает сайты для малого бизнеса. Работаем по Санкт-Петербургу, первая ниша — барбершопы.
- Прямым клиентам пишем от имени **Ярослав**. На Kwork используется псевдоним **Мирослав** — не смешивать каналы.
- Ярослав сам отправляет все сообщения клиентам (WhatsApp с рабочего номера, Telegram, VK). Агенты **только готовят тексты** — никогда не пишут клиентам напрямую.
- Команда: Координатор (главный) + Клиенты, Поиск, Сайты, Документы, Проверка. Исполнители общаются только через Координатора.

## Инфраструктура
- Репозиторий: `github.com/cByatoy/sites` — **публичный** (приватные репозитории недоступны, апелляция в GitHub на рассмотрении).
- Публикация: **GitHub Pages** → `https://cbyatoy.github.io/sites/...` — открывается в России без VPN.
  - Netlify (`*.netlify.app`) в России без VPN **не открывается** — клиентам не отправлять.
  - Если публикация Pages зависла («in progress deployment»): Ярослав в Settings → Pages ставит Source = None, потом обратно `main` / `root`.
- Боевые сайты клиентов — на **российском хостинге** (Beget / Timeweb), домен и хостинг оформляются на клиента.

## Закон — что делаем мы, что клиент
- Мы: политика конфиденциальности и cookie-баннер (шаблон), отдельная галочка согласия у форм (не отмечена заранее), только российские сервисы для форм, шрифты на своём хостинге (не Google Fonts) на боевых сайтах, только Яндекс Метрика, тексты на русском (латиница — только дублированием), реквизиты в подвале.
- Клиент (он оператор ПД): уведомление Роскомнадзора, юридическая проверка текстов. **Мы с РКН не помогаем** — решение Ярослава.
- Чек «Мой налог» на каждую оплату (на ИНН ИП/ООО клиента).
- Массовые рассылки запрещены — только личные сообщения, 10–15 в день.
- Отказываться: оплата криптой/через обменник, «давай мимо Kwork», копии чужих брендов (риск фишинга), ПД без согласия.

## Честность (уроки, которые уже стоили нам ошибок)
- Писать клиенту только то, что **проверено сегодня глазами**: скрипты уже дважды пропускали цены, которые подгружаются на странице позже.
- Указывать точный источник: «в вашей карточке на Zoon», а не «в картах», если взяли с Zoon.
- Не выдумывать данные клиента (часы, мастеров, специализации) — оставлять пометку «уточним».
- Перед сообщением Ярослав проверяет Яндекс Карты: работает ли бизнес и нет ли уже хорошего сайта.
