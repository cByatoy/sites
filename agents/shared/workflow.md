# Как работают агенты вместе

Все исполнители общаются **только через Координатора** (звезда), напрямую друг другу не пишут.

```
                    ┌──────────── Поиск (лиды, волны сообщений)
                    │
 Ярослав ◄──► Координатор ◄──► Клиенты (ответы, цена, бриф)
                    │
                    ├──────────── Документы (договор, акт, политика, КП)
                    │
                    ├──────────── Сайты (концепты, сайты, портфолио)
                    │                 │
                    └──────────── Проверка (QA) ◄┘ каждый сайт проходит QA до отправки клиенту
```

Типовой путь клиента:
1. **Поиск** готовит волну → Ярослав отправляет.
2. Клиент ответил «да» → **Клиенты** готовят ответ → Координатор ставит задачу **Сайтам** на концепт.
3. Концепт готов → **Проверка** → «можно отправлять» → Ярослав отправляет ссылку.
4. Клиент хочет сайт → **Клиенты**: цена, условия, бриф → **Документы**: договор.
5. Материалы получены → **Сайты** делают сайт → **Проверка** → правки → клиент принимает → **Документы**: акт.
6. Оплата → чек → переезд на боевой домен → **Проверка** боевого сайта → **Документы**: инструкция клиенту.

## Роли
| Агент | Делает | Не делает |
|---|---|---|
| **Координатор** | распределяет задачи, следит за сроками и статусами, ведёт CRM, передаёт данные между агентами | не пишет код сайтов, не ищет лиды сам |
| **Клиенты** | отвечает на сообщения клиентов (готовит тексты), квалифицирует, собирает бриф по чек-листу, считает цену | не делает сайты и документы, не ищет новых |
| **Поиск** | находит и проверяет новые компании, готовит волны сообщений | не ведёт переговоры |
| **Сайты** | делает концепты, сайты, публикует, обновляет портфолио | не общается с клиентами |
| **Документы** | договоры, акты, КП, политика ПД, согласия, инструкции клиенту | не обещает клиенту условия, которых нет в переписке |
| **Проверка (QA)** | тестирует каждый концепт и сайт до отправки клиенту и после запуска | не чинит сам — возвращает Сайтам |

## Статусы клиента (одинаковые везде)
`Не писал → Написал → Напомнил → Ответил → Концепт → Цена → Созвон → Бриф → Договор → В работе → Сдан → Оплачен → Поддержка` · `Отказ` · `Не актуально`

## Как передаём задачи
Сообщение между агентами (через `send_message`) или Ярославом — всегда в формате из `shared/handoff-template.md`.
Данные клиента — в CRM (Claude Docs), в сообщении только ссылка/название и что сделать.

## Сроки, за которыми следит Координатор
- Напоминание без ответа: через 3–5 дней, один раз; затем последнее мягкое — ещё через 4–5 дней; потом «Отказ, вернуться через месяц».
- Концепт после «да»: в течение суток.
- Ответ клиенту, который задал вопрос: в тот же день.
- Сайт после получения материалов: 5–7 рабочих дней.
- Проверка QA: в тот же день, как Сайты сообщили «готово».
- Договор: в течение дня после получения реквизитов.
