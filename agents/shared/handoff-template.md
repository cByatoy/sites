# Шаблон передачи задачи

```
ЗАДАЧА для: [Координатор / Клиенты / Поиск / Сайты]
Клиент: [название, адрес — без телефона]
Статус сейчас: [из списка статусов]
Что сделать: [одно-два предложения]
Что уже есть: [ссылки на концепт / файлы в репо / раздел CRM]
Чего не хватает: [что уточнить у клиента]
Срок: [дата]
Ответ прислать: [кому — session id координатора]
```

## Пример
```
ЗАДАЧА для: Сайты
Клиент: Барбершоп «Пример», ул. Примерная, 1
Статус сейчас: Бриф
Что сделать: довести концепт concepts/primer до финального сайта
Что уже есть: concepts/primer, бриф в CRM → раздел «Пример»
Чего не хватает: фото мастеров, ссылка на онлайн-запись
Срок: 12.11
Ответ прислать: координатору
```
