# Чек-лист агента «Клиенты»: что узнать у клиента до старта

Цель — собрать всё, чтобы «Сайты» сделали работу без лишних кругов правок.
Не вываливать список целиком: задавать 2–4 вопроса за сообщение, начиная с главного. Отмечать полученное в CRM.

## Этап 1. Квалификация (до цены)
- [ ] Кто принимает решение и кто будет на связи (имя, роль)
- [ ] Сколько точек/филиалов, адреса
- [ ] Как сейчас записываются клиенты: живая очередь / онлайн-запись / звонок
- [ ] Есть ли сайт или домен сейчас (и что с ним не так, по их мнению)
- [ ] Хотят ли сами менять цены/акции (→ админка +5 000 ₽) или правки через нас
- [ ] Сроки: к какой дате нужен сайт и почему
- [ ] Что-то сверх концепта? (страница мастеров, сертификаты, вакансии, второй язык) → посчитать заранее

## Этап 2. Цена и условия (отправить письменно)
- [ ] Цена и что в неё входит (см. `shared/rules.md`)
- [ ] Срок: 5–7 рабочих дней после получения материалов
- [ ] Оплата после сдачи, договор + акт, чек самозанятого
- [ ] 2 круга правок (= один общий список замечаний за раз), гарантия 14 дней, первый месяц мелкие правки бесплатно
- [ ] Домен и хостинг — на клиента, ~200–300 ₽/мес
- [ ] Получено письменное «да, делаем»

## Этап 3. Материалы для сайта
**Обязательное**
- [ ] Название в точности, как на вывеске (+ кириллицей для дублирования)
- [ ] Логотип: SVG / PDF / PNG без фона (или фото визитки — тогда сделаем сами)
- [ ] Фирменные цвета и стиль (визитки, вывеска, Instagram — «что нравится»)
- [ ] Адрес(а), часы работы каждой точки, телефон, мессенджеры (WhatsApp, Telegram, VK, Instagram)
- [ ] Ссылка на онлайн-запись (YCLIENTS / DIKIDI / Яндекс / Zoon) для каждой точки
- [ ] Актуальный прайс (по уровням мастеров, если есть) и постоянные акции
- [ ] Мастера: имена, уровень, специализация, фото (с их согласия)
- [ ] Фото зала, входа, работ — с телефона при дневном свете, 5–15 шт.

**Желательное**
- [ ] Чем отличаются от соседей (2–3 причины выбрать их)
- [ ] Отзывы: можно ли подключить виджет Яндекса / какие 3–4 отзыва показать
- [ ] Сайты, которые нравятся (2–3 ссылки)

## Этап 4. Юридическое и технические доступы
- [ ] Реквизиты для договора: ИП или ООО, ИНН, ОГРН, юр. адрес, кто подписывает
- [ ] Реквизиты для подвала сайта (те же)
- [ ] Домен: есть ли; если нет — какой хотят (проверить свободен ли)
- [ ] Регистратор и хостинг: клиент регистрируется сам (подсказываем шаги) и даёт временный доступ
- [ ] Яндекс-аккаунт для Метрики (создают они, дают нам доступ)
- [ ] Кто внесёт ссылку на сайт в Яндекс Бизнес и 2ГИС (обычно они сами, подсказываем)

## Этап 5. Сдача
- [ ] Ссылка на готовый сайт отправлена, получен общий список правок
- [ ] Правки внесены (круг 1 / круг 2)
- [ ] Получено «принято», подписан акт
- [ ] Получена оплата, отправлен чек
- [ ] Переезд на боевой домен, сняли noindex, Метрика/цели/Вебмастер
- [ ] Переданы доступы и исходники
- [ ] Предложена поддержка, попросили отзыв и разрешение показать в портфолио

## Как передать в «Сайты»
Когда закрыты этапы 2–3 (или достаточно для старта) — сообщение Координатору по шаблону `shared/handoff-template.md`: что делать, где лежат материалы, чего ещё нет.
