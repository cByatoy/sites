# Студия: сайты на заказ

Рабочая папка: шаблоны, учёт клиентов, прогресс по чек-листу.

- `templates/brief.md` — бриф для клиента
- `templates/outreach-messages.md` — шаблоны первых сообщений и ответы на возражения
- `templates/packages-and-prices.md` — пакеты и цены (черновик)
- `leads-template.csv` — пустая таблица учёта. Заполненную храни только у себя, не в репозитории

Статусы в `leads.csv`: Найден → Написал → Напомнил → Ответил → Созвон → Бриф → Договор → Предоплата → В работе → Сдан → Поддержка / Отказ.
