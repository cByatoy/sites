# Договоры и акты (исполнитель — самозанятый)

Шаблоны в `docx/`. Жёлтым подсвечены поля для заполнения. Перед первым использованием покажи юристу.

| Файл | Когда использовать |
|---|---|
| `01-dogovor-yurlico-ip-predoplata-50.docx` | Заказчик — ООО или ИП, предоплата 50 % |
| `02-dogovor-yurlico-ip-bez-predoplaty.docx` | Заказчик — ООО или ИП, оплата после сдачи |
| `03-dogovor-fizlico-predoplata-50.docx` | Заказчик — обычный человек, предоплата 50 % |
| `04-dogovor-fizlico-bez-predoplaty.docx` | Заказчик — обычный человек, оплата после сдачи |
| `05-akt-yurlico-ip.docx` | Акт сдачи-приёмки для ООО / ИП |
| `06-akt-fizlico.docx` | Акт сдачи-приёмки для физлица |

В каждом договоре внутри: Приложение 1 (ТЗ) и Приложение 2 (этапы, сроки, стоимость).

## Заложенные условия
- Срок проверки работы заказчиком — 3 рабочих дня, потом работа считается принятой.
- Правки: 2 круга (для многостраничного сайта поставь 3 в п. 4.4 и Приложении 1).
- Гарантия — 14 календарных дней.
- Права на сайт переходят заказчику после полной оплаты.
- Неустойка 0,1 % в день, максимум 10 % (для физлиц — только для заказчика, см. ниже).
- Домен и хостинг — на имя заказчика, за его счёт.
- Код может лежать в публичном GitHub, без паролей и персональных данных.
- Подписание сканами/фото по почте и в мессенджерах. Споры — суд в Санкт-Петербурге (для юрлиц).

## Важно про физлиц
С физлицом действует закон «О защите прав потребителей». Его нельзя ухудшить договором:
- за просрочку исполнитель платит неустойку 3 % в день от цены работ (максимум — вся цена). Поэтому сроки в договоре с физлицом ставь с запасом;
- заказчик может отказаться от договора в любой момент, оплатив только сделанное;
- подсудность заказчик выбирает сам.

## Как оформлять
1. Заполни поля, удали подсветку (Главная → цвет выделения → «Нет цвета»).
2. Отправь заказчику в Word или PDF, получи скан/фото с подписью.
3. На каждую оплату пробей чек в «Мой налог». Для ООО/ИП укажи ИНН и название заказчика.
4. Нумерация: договор `2026-01`, акт с тем же номером.

## Как изменить шаблоны
Тексты лежат в `build-documents.js`. После правки: `node business/documents/build-documents.js`.
